นโยบายความเป็นส่วนตัว

Privacy Policy · ปรับปรุงล่าสุด / Last updated: 23 October 2026

1. SANN MITI คืออะไร

SANN MITI เป็นโปรแกรมส่วนตัวที่ทำงานบนคอมพิวเตอร์ของเจ้าของ ใช้โพสต์รูปและคลิปลงบัญชีโซเชียลของเจ้าของเองเท่านั้น ไม่ได้เปิดให้บุคคลทั่วไปใช้

2. ข้อมูลที่โปรแกรมเข้าถึง

  • YouTube (ผ่าน YouTube API Services): ชื่อช่อง รูปช่อง จำนวนผู้ติดตาม และจำนวนคลิป ของช่องที่เจ้าของเชื่อมต่อ และสิทธิ์อัปโหลดคลิปลงช่องนั้น
  • Facebook / Instagram / Threads / TikTok: ชื่อและรูปของเพจหรือบัญชีที่เจ้าของเชื่อมต่อ และสิทธิ์โพสต์ลงบัญชีนั้น
  • รูป คลิป และแคปชั่นที่เจ้าของเลือกโพสต์เอง

โปรแกรมไม่อ่านข้อมูลของผู้ชม ผู้ติดตาม ความคิดเห็น หรือข้อความส่วนตัว

3. ข้อมูลถูกเก็บที่ไหน

รหัสเชื่อมต่อ (token) ประวัติโพสต์ และไฟล์ที่อัปโหลด เก็บอยู่ในคอมพิวเตอร์ของเจ้าของเท่านั้น ไม่มีเซิร์ฟเวอร์กลาง ข้อมูลจะถูกส่งไปยัง Google/YouTube, Meta หรือ TikTok เฉพาะตอนที่เจ้าของสั่งโพสต์ เพื่อให้โพสต์นั้นขึ้นบนบัญชีของเจ้าของ

4. การแบ่งปันข้อมูล

เราไม่ขาย ไม่ให้เช่า และไม่แบ่งปันข้อมูลให้บุคคลที่สาม และไม่ใช้ข้อมูลเพื่อโฆษณา

5. YouTube และ Google

โปรแกรมนี้ใช้ YouTube API Services การใช้งานส่วนนี้อยู่ภายใต้ ข้อกำหนดการให้บริการของ YouTube และ นโยบายความเป็นส่วนตัวของ Google การใช้ข้อมูลที่ได้รับจาก Google API เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนดเรื่อง Limited Use

6. การยกเลิกสิทธิ์และลบข้อมูล

เจ้าของยกเลิกสิทธิ์ของโปรแกรมได้ตลอดเวลาที่ หน้าสิทธิ์ของบัญชี Google หรือที่หน้าตั้งค่าสิทธิ์แอปของ TikTok / Facebook หรือกด "เอาออก" ในหน้าตั้งค่าของโปรแกรม ซึ่งจะลบรหัสเชื่อมต่อออกจากคอมพิวเตอร์ทันที

English summary

What it is. SANN MITI is a private desktop tool that runs on its owner's computer and posts the owner's own photos and videos to the owner's own accounts. It is not offered to the public.

Data accessed. Through the YouTube API Services: the connected channel's name, picture, subscriber count and video count, and permission to upload videos to that channel. For Facebook, Instagram, Threads and TikTok: the connected page/account name and picture and permission to post. It does not read viewers', followers' or commenters' data or private messages.

Storage. Access tokens, post history and uploaded files are stored only on the owner's computer. There is no central server. Data is sent to Google/YouTube, Meta or TikTok only when the owner publishes a post.

Sharing. No data is sold, rented or shared with third parties, or used for advertising.

YouTube and Google. This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service; see the Google Privacy Policy. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Access can be revoked at any time at Google Account permissions, in the TikTok or Facebook app-permission settings, or by pressing "Remove" in the app's settings, which deletes the stored token from the computer.
